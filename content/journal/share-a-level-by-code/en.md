A level can be shared as a short code. Anyone who has the same level set can open the same puzzle from it, if that level is open in their app. No server or account is involved.

## What the code holds

A code starts with MB. After that come two groups joined by a hyphen. The first group has three characters: one that marks the level set, and two that give the level number. The second group has three characters, a short check made from the level set mark, the number and the arrangement of the bottles. The code does not hold your moves, your stars or your progress.

## What the check is for

The level set mark and the check are compared with the level on the other phone. If either one does not match, the code is refused. That way you never open a different puzzle by mistake. A code made from an older level set has to be made again by the sender. Capital letters are not required, and spaces and hyphens are ignored. The letters O, I and L are read as the digits 0 and 1, so a code typed by hand is forgiving.
