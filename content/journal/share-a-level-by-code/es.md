Un nivel se puede compartir como un código corto. Cualquiera que tenga el mismo conjunto de niveles puede abrir con él el mismo rompecabezas, si ese nivel está desbloqueado en su app. No interviene ningún servidor ni ninguna cuenta.

## Qué contiene el código

Un código empieza por MB. Después vienen dos grupos unidos por un guion. El primer grupo tiene tres caracteres: uno que identifica el conjunto de niveles y dos que indican el número del nivel. El segundo grupo también tiene tres caracteres, una comprobación corta hecha a partir de la marca del conjunto de niveles, el número y la disposición de las botellas. El código no incluye tus movimientos, tus estrellas ni tu progreso.

## Para qué sirve la comprobación

La marca del conjunto de niveles y la comprobación se comparan con el nivel del otro teléfono. Si alguna de las dos no coincide, el código se rechaza. Así nunca abres otro rompecabezas por error. Un código hecho con un conjunto de niveles anterior tiene que volver a generarlo quien lo envió. No hace falta usar mayúsculas, y los espacios y guiones se ignoran. La O se lee como el dígito 0, y la I y la L como el dígito 1, así que un código escrito a mano admite pequeñas confusiones.
