Un niveau peut être partagé sous la forme d'un court code. Toute personne qui a la même série de niveaux peut ouvrir le même casse-tête avec ce code, si ce niveau est débloqué dans son app. Aucun serveur ni aucun compte n'entre en jeu.

## Ce que contient le code

Un code commence par MB. Viennent ensuite deux groupes reliés par un trait d'union. Le premier groupe compte trois caractères : un qui identifie la série de niveaux et deux qui donnent le numéro du niveau. Le second groupe compte aussi trois caractères : un court contrôle calculé à partir de la marque de la série, du numéro et de la disposition des bouteilles. Le code ne contient ni vos coups, ni vos étoiles, ni votre progression.

## À quoi sert le contrôle

La marque de la série de niveaux et le contrôle sont comparés avec le niveau présent sur l'autre téléphone. Si l'un des deux ne correspond pas, le code est refusé. Ainsi, vous n'ouvrez jamais un autre casse-tête par erreur. Un code créé avec une ancienne série de niveaux doit être recréé par la personne qui l'a envoyé. Les majuscules ne sont pas obligatoires, et les espaces et les traits d'union sont ignorés. La lettre O est lue comme le chiffre 0, et les lettres I et L comme le chiffre 1 : un code saisi à la main pardonne donc les petites confusions.
