Ein Level per Code teilen

Veröffentlicht: 2026-11-26 15:15 KST

Ein Level lässt sich als kurzer Code teilen. Wer dieselbe Levelzusammenstellung hat, kann damit dasselbe Rätsel öffnen, sofern dieses Level in seiner App freigeschaltet ist. Dafür braucht es weder einen Server noch ein Konto.

Was der Code enthält

Ein Code beginnt mit MB. Danach folgen zwei Gruppen, die durch einen Bindestrich verbunden sind. Die erste Gruppe hat drei Zeichen: eines kennzeichnet die Levelzusammenstellung, zwei geben die Levelnummer an. Die zweite Gruppe hat ebenfalls drei Zeichen. Sie bilden eine kurze Prüfung aus dem Kennzeichen der Levelzusammenstellung, der Nummer und der Anordnung der Flaschen. Deine Züge, deine Sterne und dein Fortschritt stehen nicht im Code.

Wozu die Prüfzeichen dienen

Das Kennzeichen der Levelzusammenstellung und die Prüfzeichen werden mit dem Level auf dem anderen Telefon verglichen. Passt eines davon nicht, wird der Code abgelehnt. So öffnest du nie versehentlich ein anderes Rätsel. Einen Code aus einer älteren Levelzusammenstellung muss der Absender neu erstellen. Großbuchstaben sind nicht nötig, Leerzeichen und Bindestriche werden ignoriert. O wird als die Ziffer 0 gelesen, I und L als die Ziffer 1. Ein von Hand eingetippter Code verzeiht also kleine Verwechslungen.
